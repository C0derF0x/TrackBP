# TrackBP 🩺

### Your Personal Blood Pressure Tracker

TrackBP is a Flutter-based blood pressure tracking application designed to help users record, monitor, and understand their blood pressure readings through a clean and intuitive interface.

The goal is to make blood pressure tracking simple, accessible, and informative.

## ✨ Features

- **Dashboard:** Get an overview of your blood pressure readings and recent activity.
- **Record Measurements:** Save systolic pressure, diastolic pressure, pulse rate, and measurement details.
- **Arm Selection:** Record whether a measurement was taken from the left or right arm.
- **Measurement History:** View and manage previously recorded readings.
- **Analytics:** Visualize blood pressure trends through interactive charts.
- **Flexible Time Periods:** Analyze readings across the last 7 days, 30 days, or 12 months.
- **CSV Export:** Export measurement data for external analysis.
- **User Profiles:** Manage personal profile information.
- **Customizable Appearance:** Switch between supported app themes.

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **Charts:** FL Chart
- **Storage:** Local database
- **Architecture:** Feature-based project structure

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- An Android emulator or physical device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/C0derF0x/TrackBP.git
   ```

2. Navigate to the project directory:

   ```bash
   cd TrackBP
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
